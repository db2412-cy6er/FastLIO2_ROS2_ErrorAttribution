# P4 方向性抑制（Attribution-aware Directional Update）：实现、实验与结论

*文档版本：v1.0 · 2026-08-30 · P4 技术版*

---

## 0. 一句话总结

在 FAST-LIO 的 **ESKF state correction 层**实现方向性投影（默认 identity，零侵入），
用 P2 的 Error Attribution 做 gate（几何退化才允许、匹配失败必须关闭）。经过
**标定集 + holdout 严格 A/B**（median-of-3）验证：

> **方向性抑制无法缓解严重几何退化（single_plane holdout 变差 3.7×），
> 但在 correspondence fault 场景有改善迹象（15~50%），且 matching gate 验证有效。**

P4 从数据上确认：**问题的本质不在"整体 vs 方向"的权重调节，而在任何"把状态估计从
LiDAR 弱约束交给 IMU"的操作在 IMU 精度有限时都是净损失**。这与 P3 的负面结论互相印证，
并把有效路径收敛到"识别 fault 并做稳健处理"（P5）。

## 1. 背景与动机（P1→P2→P3→P4 逻辑链）

| 阶段 | 结论 | 对 P4 的启示 |
|---|---|---|
| P1 | 几何退化可检测（Ht/Hr 特征比 + weak_direction 世界系） | 提供抑制方向和触发信号 |
| P2 | 误差归因区分 geometry vs matching vs IMU 低激励 | 提供 gate（matching failure 时方向本身失真） |
| P3 | **整体降权无效**（single_plane 变差 4.5×，fault 变差 8.7×） | 证明"整帧降权"错误 → 试"只压弱方向" |
| **P4（本次）** | **方向性抑制同样无法缓解几何退化**；fault 场景有改善 | 证明"降权/抑制 correction"路线整体证伪 |

P3 的失败被归因为"把强方向一起降了"。P4 的设计初衷是"只压弱方向、保留强方向"——
这是 P3 数据逻辑上指向的正解。**实验结果却显示这在严重几何退化上同样失败**，
根因见 §6。

## 2. 实现：esekfom state-layer directional projector

### 2.1 设计决策（响应 P4 评审）

| 评审点 | 决策 |
|---|---|
| R1 "Jacobian scaling ≠ correction suppression" | **改为 state correction 层投影**（不改 h_x） |
| R4 covariance 一致性 | **K_x 的 pos 行同步投影**，`P=(I−K_pH)P` 不过度自信 |
| R6/R7 detector 分离 | P1 永远用 raw h_x；P4 只作用 esekfom state 层，**天然隔离** |
| R14 translation-only trigger | 用 `trans_ratio < threshold_t`，独立于 rotation |
| R15/R16 P2 matching gate | `geometry_bad && matching_ok` 才允许；failure 时关闭 |
| R13 ht_accum 独立开关 | `ht_accum_enable` 布尔，不用 0 值承担"关闭" |
| R19/R20 数据泄漏 | single_plane_run1 只标定；**新录 single_plane_run2 做 holdout** |
| R22 保守 beta 网格 | 从 {0.3, 0.5, 0.7} 起步（不先试 β→0） |

### 2.2 核心代码（数学语义）

**`esekfom.hpp` `update_iterated_dyn_share_modified(double R, double &solve_time,
const Vector3d *dir_proj_w = nullptr, double dir_proj_beta = 1.0)`**：

- 插入点 A（`dx_` 计算后、`boxplus` 前）：`dx_.segment<3>(0) ← Π_β(dx_.segment<3>(0))`
- 插入点 B（`P_ = L_ − K_x·P_` 前）：K_x 的 pos 三行（前 12 列）逐列投影

其中投影 `Π_β(v) = v − (1−β)·(v·w_t)·w_t`，`w_t` = 上一帧 `weak_translation_direction`
（世界系，Ht 最小特征向量）。**β=1 或 w=nullptr ⇒ 与 p3-final 数值等价**。

**laserMapping.cpp**：
- `update_directional_cache()`：update 后填充 `dir_cache_`（one-frame delay 方向/ratio/gate/IMU 激励）
- `compute_directional_trigger()`：`translation_degen && matching_ok` → 输出 (w, β)
- `compute_directional_matching_gate()`：P2 is_matching_failure 布尔（冻结阈值 + 独立 30s rolling baseline）
- Ht 时间累积：`ht_cum = α·Ht + (1−α)·ht_cum` 再特征分解（避免 eigenvector sign ambiguity）

**LioHealth.msg +6 字段**：`directional_active / beta_applied / suppressed_weak_direction[3]
/ directional_reason / translation_severity / matching_gate_passed`（事后归因 R26）。

### 2.3 零侵入验证

`directional.enable=false`（默认）回放 corridor_run2：
- ATE mean = 0.0389（P3 degen 组 median 0.0376，单次浮动范围内）✓

| 验证 | 结果 |

## 6. 结论与机制分析

### 6.1 核心结论

1. **正常/轻微退化场景：安全**（normal 零影响、corridor 持平）——directional 不误伤。
2. **严重几何退化（single_plane）：无效甚至有害**（标定集持平/变差，holdout 3.7× 变差）。
3. **correspondence fault 场景：有改善迹象**（15~50%），且 matching gate 正确阻断。
4. **与 P3 共同结论**：**"降权/抑制 LiDAR correction"路线（无论整体还是方向性）整体证伪**。

### 6.2 为什么方向性抑制也失败（机制分析）

- **弱方向 correction 也携带一致性信息**：single_plane 场景中 weak_direction 稳定
  （相邻帧 |dot|=1.0，主方向 y），说明**不是方向估计错误**；抑制 y 方向 correction 后，
  该方向完全交给 IMU → IMU 的 y 方向漂移累积（single_plane 中 y 不可观测）。
- **"弱约束" ≠ "有害约束"**：scan-to-map 的弱方向残差即使噪声大，也约束了状态的
  **相对一致性**（防止 IMU 死区漂移）。完全抑制它等价于"在不可观测方向只信 IMU"，
  在 IMU 精度有限时是净损失——这正是 P3 已发现的"把信息交给 IMU"陷阱的方向性版本。
- **covariance 一致性**：即使 K 行投影保持了 `(I−K_pH)P` 一致（P 不过度自信），
  P 沿弱方向保持保守 → 下一帧 IMU 先验权重上升 → 状态更快漂向 IMU 轨迹。**保守的
  协方差在退化方向反而加速了"放弃激光"**（设计正确但目标错误）。

### 6.3 fault 场景改善的机制（审慎归因）

fault 段 gate 阻断 directional（与 degen 相同），clean 段 directional 与 degen 持平
（corridor 0.0396 vs 0.0372）。因此 fault 场景的 −15%/−50% **不能简单归因于
directional 的抑制增益**。可能的解释：

- **回放非确定性**：fault 场景 ATE 方差极大（stress degen 0.07~30m），median 对比不稳健；
- **fault 后恢复差异**：directional 使 fault 前的 P 沿弱方向更保守，fault 后可能更快恢复；
- **clean 段微小的 correction 变化** 在 fault 前恰好改变了误差相位。

**结论：fault 场景的改善"有倾向但机制不明"，需更大样本验证，不能作为 directional 有效的证据。**
但 **matching gate 的正确性是被确认的**（fault 期间不误触发）——这是 P2 归因在
实际控制器中的有效应用。

## 8. 边界与未来方向

### 8.1 P4 的边界（如实声明）

- 方向性抑制在**严重几何退化**（single_plane）上被证伪（holdout 3.7× 变差）；
- fault 场景的改善倾向**样本不足以定论**（3 runs，方差大），且机制不明；
- 未覆盖：open_ground、更长的 fault 段、IMU safety limiter 联动（v1 只记录）。

### 8.2 数据指向的有效方向（P5 立项依据）

1. **Robust matching / 失效冻结**：fault 场景的改善来自"识别 fault 并关闭几何抑制"
   → 方向应是"fault 期间冻结 LiDAR update 或使用 robust cost"，而非任何形式的降权。
2. **Current-frame emergency gate**：fault 首帧保护（P3 已发现的 one-frame delay 盲区）。
3. **多传感器 / 闭环**：单面墙的不可观测方向本质上是**信息缺失**，任何"少用激光"
   都无法创造信息；只有额外信息源（IMU 双积分之外）才能约束。

### 8.3 技术遗产（即使方案证伪）

- 完整的 esekfom state-layer directional projector（数学语义正确 + cov 一致性）——
  任何未来"方向性状态处理"（如可观测性感知的 update 冻结）都可复用；
- synthetic test / parity / 数据划分纪律——方法论资产。

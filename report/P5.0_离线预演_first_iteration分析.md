# P5.0 离线预演报告：first-iteration 统计分布与 current-frame gate 可行性

> 日期: 2026-08-30 · 阶段: P5.0 · 状态: 完成
> 前置: P2 冻结阈值（attribution_params.yaml v1.1）在 **final-iteration** 标定；
>   P5 gate 判断的是 **first-iteration**（IMU propagated pose 下的 KD-tree matching），
>   分布可能不同 → 本阶段用真实 replay 数据重新验证。

## 1. 数据采集（debug 模式）

- 工具: `replay --debug-iterations` → `degen_iterations.csv` 增加
  `candidate_feature_num / effective_feature_ratio / residual_p90` 三列。
- `iteration==1` 行 = first-iteration 统计（`degen_data.iter_count` 在 h_share_model 内
  自增，第一次迭代后 =1；经 CSV 验证唯一映射成立）。
- 采集矩阵（each 1 replay, P5.0 为分布预演非正式 A/B）:

| exp | 场景 | 数据 |
|---|---|---|

| experiment_141 | corridor_run2 + V5 holdout fault (seed=7) | 890 帧 |

## 2. 关键发现

### 2.1 first-iter vs final-iter 分布差异（决定阈值复用）

| 场景 | eff_num p50 (first/final) | mean_res p50 (first/final) | p90_res p50 (first/final) |
|---|---|---|---|
| corridor_clean | 491 / 492 | 0.0039 / 0.0036 | 0.0091 / 0.0087 |
| V5_holdout | 316 / 100 | 0.0064 / 0.0246 | 0.0198 / 0.0678 |
| stress | 207 / 213 | 0.0063 / 0.0112 | 0.0127 / 0.0507 |

**clean 场景 first≈final；fault 场景 first-iter 的 eff_num/残差都远好于 final-iter**。
原因: first-iter 用 IMU 传播位姿（尚未被坏 correspondence 污染），dropout/outlier
减少点数但残差仍低；IEKF 收敛过程才把坏匹配推高。**直接复用 P2 final-iteration 阈值
在 first-iter 上必然误判（方向完全相反）。**

### 2.2 P2 absolute 阈值直套 first-iter（验证不可行）

| exp | clean 误拒率 | fault 命中率 |
|---|---|---|
| V5_holdout | 52.7% | 37.1% |
| stress | 59.5% | 51.8% |
| normal_indoor | 99.8% (p90>0.04 帧 593/594) | - |

**absolute residual 阈值跨场景不泛化**（normal_indoor 干净场景 first-iter p90_res p50=0.058，
远超 P2 的 0.04~0.08 量级）→ 任何 absolute residual/eff 阈值都会大量误拒。结论:
**P2 冻结的 feats_low/residual 通道不可复用于 first-iter**。

### 2.3 rel-drop（rolling-baseline relative）通道在 first-iter 上完全可分（P5 基础）

采用 P2 的 relative drop 通道（`rel_num < 0.40 OR rel_ratio < 0.30`，
baseline = 前 30s 非 drop 帧 median）:

| 场景 | rel-drop 触发帧数 | 触发率 |
|---|---|---|
| corridor_clean | 0 / 895 | 0.0% |
| normal_indoor | 0 / 594 | 0.0% |
| single_plane | 0 / 731 | 0.0% |
| V5_holdout | 347 / 890 | 39.0% |
| stress | 534 / 897 | 59.5% |

**3 个 clean 场景全部 0 触发，fault 场景 39~60% 帧触发**（长 fault 段连续触发符合预期，
fault 期间就是纯 IMU 传播）。相对信号不受场景绝对量级影响 → 跨场景泛化。

### 2.4 single_plane regression 检查（用户评审 #13）

single_plane 是 geometry 退化（点很多但共面）: eff_num p50=1068（不低），
ratio p50=0.974（高），residual 正常（mean_res 0.0061），**rel-drop 触发 0 帧**。
→ **geometry 退化不会触发 P5 matching gate**，与 correspondence failure 路径真正分离。

### 2.5 信号时间特性（annotations 偏移验证）

V5/stress 的 fault 效应在 health 时间轴比 annotations 早 ~3~8s（injector t0 与 health
首帧系统偏差，且各 fault 段偏移不一致）。**在线 P5 gate 不能依赖 fault 绝对时间标定，
必须以滚动 baseline 的 relative 信号在线判定。**

## 3. P5 阈值决策

1. **主判定（reject 条件）**: `rel_num < 0.40 OR rel_ratio < 0.30`
   （复用 P2 冻结的 num_drop_th / ratio_drop_th，first-iter 上验证可行，跨场景泛化）。
2. **辅助通道**: `residual_p90 相对滚动 baseline 飙升`（如 rel_p90 > 2.0）用于
   outlier/noise 型 fault（V5/stress p90_res 峰值 0.14~0.22 vs clean 0.009~0.018），
   但必须 relative 化，**不设 absolute 阈值**。
3. **不使用** P2 冻结的 feats_low / residual_high absolute 通道（跨场景不泛化）。
4. **single_plane 防护**: rel-drop 不触发已自动满足用户评审 #13 的"特征少但残差正常
   不误杀"要求；P5 gate 组合条件为 (rel_drop) AND (非纯 geometry 标志) 的双重校验
   （实现时用 degen_data 的 trans_ratio 佐证——geometry 严重退化时不单独以点数判定）。

## 4. 止损线评估

**current-frame gate 可行性: 通过。** 信号可分（clean 0 误报 / fault 39~60% 检出）、
geometry 与 correspondence 分离（single_plane 0 触发）、阈值机制确定
（relative 通道 + relative residual 辅助）。**无需降级为"点数骤降粗检 + P4 gate"方案。**
